# PennyWise

A local-first personal finance manager, expense tracker, and flexible budget planner for Android built with Expo.

## Language

### Wallets & Currencies

**Wallet**:
A user-defined container of money denominated in a single currency (fiat or cryptocurrency) that holds a balance and records transactions (e.g., Cash, Euros, Bitcoin). Each Wallet has a fixed decimal precision matching its currency and a flag indicating whether its balance is included in Net Worth.
_Avoid_: Account, Bank Account, Portfolio, Vault

**Base Currency**:
The user's primary display and reporting currency into which all Net Worth totals, multi-currency Budgets, and cross-wallet spending insights are converted.
_Avoid_: Primary Currency, Default Currency, Home Currency

**Exchange Rate**:
The conversion multiplier from a Wallet's currency to the Base Currency, fetched automatically from a public feed and cached locally on-device with optional manual user overrides.
_Avoid_: Conversion Rate, Forex Rate

**Snapshot Rate**:
The Exchange Rate captured and stored immutably on a Transaction at the moment it occurs (or is edited), ensuring historical spending insights and past Budgets do not shift when live market rates fluctuate.
_Avoid_: Historical Rate, Locked Rate

**Net Worth**:
The sum of current balances across all Wallets marked as included in total, converted into the Base Currency using the latest cached Exchange Rate.
_Avoid_: Total Balance, Global Balance

### Transactions & Classification

**Transaction**:
A single recorded financial event affecting one or two Wallets at a specific timestamp, carrying an amount, a Snapshot Rate, an optional title/note, and one of four types: Expense, Income, Transfer, or Balance Adjustment.
_Avoid_: Entry, Record, Operation, Payment

**Expense**:
A Transaction type representing money leaving a Wallet for goods, services, or bills; reduces Wallet balance and counts toward spending insights and Budgets.
_Avoid_: Outflow, Debit, Spend

**Income**:
A Transaction type representing money entering a Wallet; increases Wallet balance and counts toward income insights.
_Avoid_: Inflow, Credit, Deposit

**Transfer**:
A Transaction type moving funds from a source Wallet (outflow amount in source currency) to a destination Wallet (inflow amount in destination currency). Excluded from spending Budgets and Income/Expense totals.
_Avoid_: Internal Payment, Exchange, Move

**Balance Adjustment**:
A system-generated Transaction created when a user manually reconciles or edits a Wallet's current balance, preserving an accurate ledger without distorting spending Budgets or insights.
_Avoid_: Manual Override, Correction Entry

**Category**:
A top-level classification for Expense or Income Transactions with a user-customizable name, icon, color, and default flow direction.
_Avoid_: Folder, Group, Bucket

**Subcategory**:
An optional second-level classification belonging to a parent Category for finer-grained spending analysis (e.g., `Food & Dining` → `Coffee`).
_Avoid_: Child Category, Tag

### Budgeting

**Budget**:
A spending target with a target limit denominated in the Base Currency (or a single Wallet's currency), evaluated over a Budget Period and filtered by a Budget Scope. Multiple Budgets can run concurrently.
_Avoid_: Spending Plan, Envelope, Cap

**Budget Period**:
The time window over which a Budget aggregates expenses—either a recurring cycle (`Weekly`, `Monthly`, `Yearly`, or custom `Every N Days/Weeks/Months` from an anchor date) or a one-time `Custom Date Range`.
_Avoid_: Billing Cycle, Timeframe

**Budget Scope**:
The rule determining which Expense Transactions count toward a Budget: either **Automatic Filter** (all Expenses matching selected Categories and/or Wallets) or **Manual Assignment** (only Expenses explicitly pinned to that Budget, such as for a trip or event).
_Avoid_: Budget Filter, Budget Rule

**Daily Spending Allowance**:
The dynamic amount a user can spend per day for the remainder of an active Budget Period without exceeding the Budget limit, calculated as `max(0, (Budget Limit - Spent in Current Period) / Remaining Days Inclusive)`.
_Avoid_: Daily Limit, Safe-to-Spend

### Bills & Recurrence

**Recurring Rule**:
A schedule definition (`Daily`, `Weekly`, `Monthly`, `Yearly`, or custom interval) that generates Upcoming Payments, configured with an `autoPay` mode and local notification reminder lead time.
_Avoid_: Subscription Template, Cron Job, Repeat Setting

**Upcoming Payment**:
A future or due scheduled financial obligation (either standalone or generated by a Recurring Rule) that has not yet been posted as a Transaction. It does not alter Wallet balances or Budget totals until settled (either automatically via `autoPay` on the due date or manually via "Mark as Paid").
_Avoid_: Pending Transaction, Future Entry, Unpaid Bill

### Insights, Personalization & Privacy

**Spending Pace Comparison**:
A cumulative day-by-day line chart overlaying the current period's cumulative Expenses against the previous equivalent period's cumulative Expenses to show whether the user is spending faster or slower than usual.
_Avoid_: Burn Rate Chart, Velocity Graph

**Home Section**:
A modular, user-orderable and toggleable dashboard block on the Home screen (e.g., Wallets Carousel, Pinned Budgets & Daily Spending Allowance, Spending Pace Comparison, Upcoming Payments, Recent Transactions).
_Avoid_: Widget, Portlet, Card Block

**Backup Snapshot**:
A self-contained, user-exported local file containing all Wallets, Categories, Subcategories, Transactions, Budgets, Recurring Rules, and Preferences for full offline backup and device-to-device restore.
_Avoid_: Cloud Sync, Database Dump

**Privacy Mask**:
A toggleable UI state that obscures monetary balances and amounts on screen when viewing the app in public.
_Avoid_: Incognito Mode, Stealth Mode
